## 克隆方式

仓库中的 PDF 通过 **Git LFS**（Large File Storage）存储，仓库本身只保存指针。

### 安装 LFS

```bash
git lfs install
```

### 完整克隆（含书籍内容）

```bash
git clone https://github.com/Sphinxes0o0/ebooks.git
```

首次克隆会下载约 22 GB 数据，请确保磁盘空间充足。

### 只取目录结构（不下载书籍）

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/Sphinxes0o0/ebooks.git
```

之后按需拉取具体文件：

```bash
cd ebooks
git lfs pull --include="数学/*.pdf"
```

### 验证完整性

```bash
git lfs fsck
```

## 使用说明

- **文件命名**：已去除下载站后缀（如 `(z-lib.org)`）与无意义数字 ID，保留书名与必要的版本、译者信息。
- **同名不同版本**：以 `_版2`、`_版3` 区分（如同一本书的扫描版与电子版）。
- **重复文件**：内容完全相同的副本已合并，仅保留一份。
- **更新**：本仓库为纯内容库，一般不做二次修改；如需同步本地新增书籍，直接 `git add` 后提交即可。
